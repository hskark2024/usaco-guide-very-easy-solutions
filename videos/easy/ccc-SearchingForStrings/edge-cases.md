# Edge-case checklist

- [ ] needle is longer than haystack
- [ ] one-character needle
- [ ] needle and haystack have equal length
- [ ] no window has the needed letter counts
- [ ] every window has the needed letter counts
- [ ] one permutation appears many times
- [ ] several different permutations appear
- [ ] repeated letters reduce the number of permutations
- [ ] windows at the first and last positions
- [ ] 200,000-character inputs
- [ ] packed hash residues preserve both components

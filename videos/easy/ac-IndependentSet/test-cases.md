# Test-case walkthroughs

For the official three-vertex path, the valid patterns are all white, each of the three single-black choices, and black-white-black. The answer is `5`.

A single vertex has `2` colorings. A four-leaf star has all-white-center cases for any leaf choices plus the one black-center case, giving `2^3 + 1 = 9` for the official four-vertex star.

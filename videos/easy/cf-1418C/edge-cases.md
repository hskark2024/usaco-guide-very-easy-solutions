# Edge-case checklist

- One easy boss: the friend takes it for zero skips.
- One hard boss: the friend must spend exactly one skip.
- All bosses are hard: session grouping is crucial.
- All bosses are easy: the answer is zero for every length.
- An odd number of bosses: either player's turn may be next after completion.
- The final session may contain only one boss.
- Across test cases, the total `N` is bounded, so rebuilding a linear DP is safe.

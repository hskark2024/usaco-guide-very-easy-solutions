# Test-case walkthroughs

The official sample starts with the twenty-minute movie at time zero, joins the fifty-minute movie while it is playing, and then uses a forty-minute showing to reach time one hundred. The answer is three.

A single movie starting at zero can finish the task alone. A movie whose first showing starts at time one cannot begin a continuous schedule. If one movie ends exactly when another begins, the handoff is valid. A later-starting showing of the same movie is always at least as useful as an earlier one when both contain the current time.

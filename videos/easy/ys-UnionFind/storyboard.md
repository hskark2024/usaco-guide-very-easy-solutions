# Storyboard

1. **Hook — friend groups**: Separate circles merge into groups as edges appear.
2. **Problem operations**: Contrast add-edge operations with connectivity questions.
3. **Parent forest**: Each component becomes a rooted tree with one representative.
4. **Find and compression**: Animate a long parent chain flattening to the root.
5. **Union by size**: Move a smaller tree under a larger root.
6. **Walkthrough**: Add `0-1`, add `1-2`, then query `0-2`.
7. **C++ and complexity**: Parent/size vectors and the near-constant amortized bound.

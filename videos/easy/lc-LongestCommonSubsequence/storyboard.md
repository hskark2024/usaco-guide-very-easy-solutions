# Storyboard and slide outline

Voice: Daniel, a calm male macOS voice for a 9th-grade audience. Each numbered narration paragraph matches one slide.

1. Show two strings with `A-C-E` highlighted in both and label the answer 3.
2. Build a prefix grid with one string on each axis and define a cell.
3. Highlight equal letters and animate a diagonal arrow plus one.
4. Highlight different letters and compare arrows from above and left.
5. Fill the `ABCDE` versus `ACE` grid and trace the three matching diagonals.
6. Fade old rows until only previous and current remain; place the shorter string on columns.
7. Display `O(nm)` time and `O(min(n,m))` memory with repeated-letter examples.
8. Close with the match/mismatch proof split and the independent test checklist.

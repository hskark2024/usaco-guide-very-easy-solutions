# Edge-case checklist

- [ ] one input value
- [ ] target reached by one half alone
- [ ] target unreachable
- [ ] many equal values
- [ ] many subsets share one sum
- [ ] empty subset included in each half list
- [ ] odd `N` creates unequal half sizes
- [ ] sums exceed 32-bit range
- [ ] answer exceeds 32-bit range
- [ ] `N=40`

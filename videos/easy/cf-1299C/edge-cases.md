# Edge-case checklist

- One tank.
- Already nondecreasing amounts.
- Strictly decreasing amounts.
- All amounts equal.
- Cascading merges across many blocks.
- Equal rational averages from different sums and lengths.
- Repeating-decimal block averages.
- Maximum amount `1,000,000`.
- Maximum `1,000,000` tanks.
- Output precision within `1e-9`.

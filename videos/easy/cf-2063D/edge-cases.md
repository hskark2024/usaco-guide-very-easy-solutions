# Edge-case checklist

- [ ] one row has only one point
- [ ] no triangle is possible
- [ ] exactly one triangle is possible
- [ ] one row limits `k_max`
- [ ] total point count limits `k_max`
- [ ] negative and positive coordinates
- [ ] highly unbalanced row sizes
- [ ] peak occurs at the left feasible boundary
- [ ] peak occurs at the right feasible boundary
- [ ] neighboring choices tie
- [ ] maximum total input size
- [ ] accumulated score exceeds 32-bit range

# Edge-case checklist

- [x] One child requires zero divider bars and has one distribution.
- [x] One apple produces exactly `n` distributions.
- [x] Adjacent bars correctly represent a child receiving zero apples.
- [x] Bars at either endpoint allow the first or last child to receive zero.
- [x] The largest factorial index is `n+m-1`, at most `1,999,999`.
- [x] Modular products use 64-bit integers.

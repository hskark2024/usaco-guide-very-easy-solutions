# Storyboard and slide outline

Voice: Daniel, a calm male macOS voice for a 9th-grade audience. Each numbered narration paragraph matches one slide.

1. Show rabbits with green positive and red negative pair scores.
2. Compare two partitions where a locally good edge changes other contributions.
3. Turn one candidate group into a bitmask card with a score.
4. Remove one rabbit and add its edges back to build the card value.
5. Pin the lowest set bit and highlight group choices containing it.
6. Combine one group card with a best-remainder card.
7. Cross out reordered duplicates while preserving each real partition.
8. Display complexity, 64-bit warning, and brute-force verification.

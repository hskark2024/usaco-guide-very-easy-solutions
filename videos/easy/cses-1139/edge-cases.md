# Edge-case checklist

- [ ] one vertex
- [ ] all vertices share one color
- [ ] every vertex has a unique color
- [ ] same color occurs in separate child branches
- [ ] root interval contains the full Euler array
- [ ] leaf interval has length one
- [ ] star-shaped tree
- [ ] maximum-depth path
- [ ] color values near one billion
- [ ] answer order follows vertex numbers, not Euler positions

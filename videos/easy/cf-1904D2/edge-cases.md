# Edge-case checklist

- [ ] length one
- [ ] arrays already equal
- [ ] an original value exceeds its target
- [ ] requested value has no original source
- [ ] valid source only on the left
- [ ] valid source only on the right
- [ ] a larger original value blocks the interval
- [ ] a smaller final target blocks the interval
- [ ] duplicate source values on both sides
- [ ] total length `200000`

# Test-case walkthroughs

For `aagog`, pair the first two `a` notes and pair the two `g` notes around `o`. Insert one additional `o`, so the answer is `1`.

For `aa`, the observed notes already form one pair, so the answer is `0`. For `a`, one matching note must be inserted, so the answer is `1`. For `ab`, neither note can pair with the other; each needs a matching insertion, giving `2`. Nested patterns such as `abba` need no insertions.

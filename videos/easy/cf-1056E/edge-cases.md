# Edge-case checklist

- [ ] both pattern symbols occur
- [ ] one symbol occurs exactly once
- [ ] the more frequent symbol is originally `1`
- [ ] remaining length is not divisible
- [ ] one replacement has length one
- [ ] replacements have equal lengths but different content
- [ ] replacements would be identical and must be rejected
- [ ] repeated target letters create many possible splits
- [ ] no valid replacement pair
- [ ] target length reaches one million

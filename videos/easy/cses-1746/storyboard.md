# Storyboard and slide outline

Voice: Daniel, a calm male macOS voice for a 9th-grade audience. Each numbered narration paragraph matches one slide.

1. Show an array with fixed numbers and question marks, plus the neighbor-difference rule.
2. Replace whole prefixes with labeled ending-value buckets.
3. Draw arrows from `v-1`, `v`, and `v+1` into the next `v`.
4. Compare an unknown column with all rows active against a fixed column with one active row.
5. Animate the sample `2 0 2` and highlight its three completions.
6. Show two DP rows swapping and the zero sentinels at both ends.
7. Present the `n×m` work and two-row memory limits.
8. Close with the predecessor-classification proof and enumeration tests.

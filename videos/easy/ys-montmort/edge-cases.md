# Edge-case checklist

- [x] `N = 1` prints only `0`.
- [x] `M = 1` makes every answer `0`.
- [x] Multiplication uses 64-bit arithmetic.
- [x] `D[0]` is stored for the `D[2]` transition but is not printed.
- [x] Output contains exactly `N` space-separated values and a final newline.
- [x] Rolling-state variables shift only after the new value is computed.

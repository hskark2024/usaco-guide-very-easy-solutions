## Proposed YouTube description

Learn how to count derangements—permutations where nothing stays in its original position—using a two-state dynamic programming recurrence. We derive the formula, trace the modulo arithmetic, prove why it works, and implement an O(N)-time, O(1)-space C++17 solution.

# Storyboard

1. **Hook — which pairs become powers?**: Show several number cards and a perfect cube target.
2. **Prime exponent columns**: Factor a number and draw one column per prime.
3. **Reduce modulo k**: Erase complete groups of `k` exponent tokens.
4. **Build the complement**: Turn residue `r` into required residue `k-r`.
5. **Left-to-right counting**: Query earlier signatures before inserting the current one.
6. **Official sample**: Highlight the five valid cube-product pairs.
7. **C++ implementation**: Walk through the SPF sieve, vector keys, map counts, and complexity.

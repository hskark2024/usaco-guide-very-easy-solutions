# Edge-case checklist

- [ ] one directed edge
- [ ] no path longer than two vertices
- [ ] several neighbors with the same value
- [ ] directed cycles
- [ ] disconnected graph components
- [ ] multiple valid continuations from one edge
- [ ] labels near `10^18`
- [ ] answer requiring modulo reduction
- [ ] 200,000 vertices and edges
- [ ] many test cases with bounded total size

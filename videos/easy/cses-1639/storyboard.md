Voice: Daniel, a calm male macOS voice for a 9th-grade audience. Each numbered narration paragraph matches one slide.

1. Show the three edit operations with `LOVE → MOVIE` as the goal.
2. Draw a prefix table with string letters along its top and left edges.
3. Highlight an equal-letter diagonal arrow labeled cost zero.
4. Show the above, left, and diagonal arrows for delete, insert, and replace.
5. Fill the table's top row and left column with increasing integers.
6. Trace a two-edit route for the official example and highlight the final 2.
7. Collapse the full table into two rolling rows and place the shorter string on columns.
8. Close with the final-operation proof and the independent whole-string BFS test.

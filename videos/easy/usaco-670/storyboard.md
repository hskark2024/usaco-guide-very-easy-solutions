# Storyboard and slide outline

Voice: Daniel, a calm male macOS voice for a 9th-grade audience. Each numbered narration paragraph matches one slide.

1. Plot H and G cow points, show ordered arrows within each breed, and label fixed start/end.
2. Show a partial route with counters `(i,j)` and a badge for the current breed.
3. Split every grid cell into an H layer and a G layer with different current locations.
4. Animate four transition types: H-to-H, H-to-G, G-to-H, and G-to-G.
5. Highlight the single zero base state and infinity elsewhere; show squared-distance edge cost.
6. Trace the sample interleaving and add edge costs to reach 20.
7. Circle only `(H,G,H)` as the legal answer and display `O(HG)` time and space.
8. Finish with the final-visit proof and exhaustive-interleaving test cards.

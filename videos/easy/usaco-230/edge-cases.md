# Edge-case checklist

- [ ] one island
- [ ] one-row or one-column map
- [ ] multi-cell island
- [ ] several equally short water routes
- [ ] deep water blocks a tempting route
- [ ] starting island is not fixed
- [ ] optimal route does not return to its start
- [ ] travel through an already visited island
- [ ] exactly fifteen islands
- [ ] `50 x 50` grid

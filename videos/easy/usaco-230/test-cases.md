# Test-case walkthroughs

The official sample contains three islands. The top-left island reaches the middle using one shallow square, and the middle reaches the bottom-right using two more, for an answer of three.

A grid containing one connected island needs no swimming, so its answer is zero.

For the one-row map `XSXSX`, three islands are separated by one shallow square each. Starting at an end and visiting across the row costs two.

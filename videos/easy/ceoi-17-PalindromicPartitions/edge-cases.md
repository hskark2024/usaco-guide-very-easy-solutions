# Edge-case checklist

- [ ] one-character string
- [ ] two equal characters
- [ ] two different characters
- [ ] every character can be its own chunk
- [ ] no matching border before the center
- [ ] matching outer chunks have length greater than one
- [ ] even number of final chunks
- [ ] odd number with one center chunk
- [ ] repeated and periodic strings
- [ ] multiple test cases
- [ ] one-million-character string
- [ ] exact check protects against hash collision

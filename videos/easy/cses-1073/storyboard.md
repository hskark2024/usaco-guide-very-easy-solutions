# Storyboard and slide outline

Voice: Daniel, a calm male macOS voice for a 9th-grade audience. Each numbered narration paragraph matches one slide.

1. Drop labeled cubes toward several towers and highlight the strict size rule.
2. Fade buried cubes while leaving the exposed top values bright.
3. Sort the top values and place a binary-search pointer on the first value greater than `x`.
4. Compare using the smallest legal top with wasting a larger flexible top.
5. Move the pointer past the row and animate a new tower appearing.
6. Walk through `3 8 2 1 5`, updating the sorted top row after every cube.
7. Put two equal cubes side by side and contrast `upper_bound` with `lower_bound`.
8. Display complexity, the exchange argument, and exhaustive verification.

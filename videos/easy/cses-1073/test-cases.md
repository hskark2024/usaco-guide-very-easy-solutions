# Test-case walkthroughs

For `3 8 2 1 5`, the sorted exposed tops evolve as `[3]`, `[3,8]`, `[2,8]`, `[1,8]`, and `[1,5]`, so the answer is two.

For `4 4 4 4`, no equal top is strictly greater than the next cube, so all four cubes need separate towers. For `5 4 3 2 1`, each new cube replaces the one exposed top, so only one tower is needed.

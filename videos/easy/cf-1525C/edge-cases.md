# Edge-case checklist

- [ ] one robot
- [ ] only opposite-parity robots
- [ ] direct adjacent `R-L` pair
- [ ] two left-movers using wall zero
- [ ] two right-movers using wall `M`
- [ ] one leftover `L` and one leftover `R`
- [ ] several robots collide at one integer point
- [ ] robots cross at a half-integer point and survive
- [ ] unsorted input coordinates
- [ ] total robot count `300000`

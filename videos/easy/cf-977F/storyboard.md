# Storyboard and slide outline

Voice: Daniel, a calm male macOS voice for a 9th-grade audience. Each numbered narration paragraph matches one slide.

1. Show an array with selected positions connected by `+1` arrows.
2. Cross out all predecessor values except `x-1`.
3. Draw a small table from ending value to best length and final index.
4. Animate the lookup of `x-1`, followed by either extend or start.
5. Draw parent arrows backward, then reverse the recovered indices.
6. Walk through `3 3 4 7 5 6 8` and highlight a length-four chain.
7. Show duplicate values sharing one best-record slot.
8. Display expected complexity and the exhaustive verifier checklist.

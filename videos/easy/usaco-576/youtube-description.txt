Learn how to count many tree paths at once in USACO Max Flow. This C++17 solution combines binary-lifting LCA queries with four difference markers per route and one bottom-up accumulation.

GitHub solution and notes: https://github.com/hskark2024/usaco-guide-very-easy-solutions/tree/main/problems/usaco-576

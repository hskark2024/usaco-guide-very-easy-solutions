# Edge-case checklist

- [ ] forbidden word occurs nowhere
- [ ] forbidden word occurs at the beginning
- [ ] forbidden word occurs at the end
- [ ] several non-overlapping occurrences
- [ ] overlapping occurrences
- [ ] a deletion creates a new boundary occurrence
- [ ] source and forbidden word have equal length
- [ ] forbidden word has length one
- [ ] long runs of the same character
- [ ] source length reaches one million
- [ ] exact comparison rejects a theoretical hash collision

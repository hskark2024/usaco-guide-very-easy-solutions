# Edge-case checklist

- One ramp position.
- Length-one operations, whose step is one.
- A progression ending exactly at `N`.
- Stop event beyond `N` but within `N + step`.
- Multiple overlapping progressions with the same step.
- Same step with different residue classes.
- Steps 320 and 321 on opposite sides of the threshold.
- Counts reaching `K` at one position.

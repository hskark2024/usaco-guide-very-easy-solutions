# Edge-case checklist

- [ ] one vertex with repeated updates
- [ ] query root after updates
- [ ] query a leaf
- [ ] update root
- [ ] star-shaped tree
- [ ] path-shaped tree of maximum depth
- [ ] new value smaller than old value
- [ ] new value equal to old value
- [ ] subtree sum larger than 32-bit integer
- [ ] interleaved updates and queries

# Storyboard and slide outline

Voice: Daniel, a calm male macOS voice for a 9th-grade audience. Each numbered narration paragraph matches one slide.

1. Show a rooted tree with values and two query cards: replace and subtree sum.
2. Animate DFS writing vertices into a horizontal Euler array.
3. Color one subtree and its matching uninterrupted array interval.
4. Transform the two tree queries into a point update and range query.
5. Draw a Fenwick tree above the array and reveal prefix subtraction.
6. Change a cell from 5 to 3 and animate a `-2` update.
7. Highlight the official subtree of vertex 3, first totaling 8 and then 10.
8. Join two proof boxes: exact interval and current stored values.
9. Replace a recursive call stack with explicit enter/exit cards and show complexity.

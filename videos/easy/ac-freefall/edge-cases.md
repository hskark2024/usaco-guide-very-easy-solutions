# Edge-case checklist

- [ ] `A < B`, so zero operations are optimal
- [ ] optimum is exactly zero
- [ ] optimum is an interior integer
- [ ] continuous minimum lies between integers
- [ ] neighboring integers nearly tie
- [ ] `A = 1`
- [ ] `B = 1`
- [ ] `A = 10^18`
- [ ] `B = 10^18`
- [ ] both inputs are maximum
- [ ] output meets absolute or relative error tolerance

# Edge-case checklist

- [ ] one distinct value
- [ ] every frequency equals one
- [ ] repeated large frequencies
- [ ] modulus equals two
- [ ] composite modulus with noninvertible factorials
- [ ] answer becomes zero modulo `M`
- [ ] many tiny test cases
- [ ] total `N` across cases is 300,000
- [ ] one sequence has total length 5000
- [ ] multiplication uses 64-bit arithmetic
